名稱

K49 系統整合與平台相容性

在以下情況下使用

同一套知識卡、Skill 或工作流需要在不同 AI 平台、作業環境或 Runtime 使用時使用。

內容

【任務辨識】確認跨平台移植後的能力、權限及執行行為是否一致。

【執行要求】

1. 區分共用規格與平台專屬 Adapter。
2. 核對平台支援的檔案格式、工具及觸發方式。
3. 驗證安裝、讀取、載入、觸發及執行狀態。
4. 測試平台差異、權限及失敗回退。
5. 保存平台、版本及 Runtime 證據。

【Skill 路由】safe-implementation、independent-audit、平台 Adapter（依實際存在狀態）。

【禁止事項】GitHub 有檔案不代表平台已安裝；平台已安裝不代表 Runtime 已生效。

【完成判準】每個目標平台均有獨立相容性與實際任務證據。

【失敗處理】不相容時標示平台限制，不宣稱跨平台完成。
