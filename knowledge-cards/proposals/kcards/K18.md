K18｜Skill 選擇與載入

名稱

K18 Skill 選擇與載入

在以下情況下使用

任務需要專業程序、可重複工作流或特定領域能力時使用。

內容

【任務辨識】從已核實的 Skill 清單中選擇最適合的能力。

【執行要求】

1. 查詢 Skill Registry 及實際檔案。
2. 核對名稱、版本、狀態、觸發條件及相依。
3. 比較既有能力，避免重複包裝。
4. 只載入本次必要 Skill。
5. 區分已存在、候選、已安裝、已載入及 Runtime 可用。

【Skill 路由】miko-skill-router（候選）、skill-registry（待評估整合）。

【禁止事項】搜尋到外部 Skill 不代表已安裝；存在不代表已採用。

【完成判準】每個選用 Skill 均有存在證據及適用理由。

【失敗處理】找不到適用 Skill 時標示能力缺口，不假裝可執行。

⸻

【驗收邊界】
資訊不足或相依資料未讀取時，狀態標記 UNKNOWN，不得自行補值。
尚未實際執行的測試標記 NOT_RUN，不得以文件完整代替執行證據。
