# ingredient-source-analysis v0.1.0-candidate

## 1. 基本資訊與核心目的

| 欄位 | 內容 |
|---|---|
| 名稱 | ingredient-source-analysis |
| 版本 | 0.1.0-candidate |
| 狀態 | PROPOSED／NOT_ADOPTED |
| 類別 | 一般成分、配方、來源與證據查詢 |
| Runtime | `SKILL.md` |

本 Skill 是所有成分查詢的共同入口。凡食品、飼料、零食、保健品、草本產品、藥品、化妝品或人用產品涉及「成分是什麼、來源／源頭是哪裡、可能用途、證據、風險或是否適合」，都先逐項核對。本 Skill 不預設使用者在問狗；只有使用者明確提到狗或其他動物時，才加入該物種的安全性與證據層；只有明確提到嘿姆時，才串接 `hemo`。

## 2. 觸發與負向觸發

| 情境 | 處理 |
|---|---|
| 詢問任何成分、完整配方、賦形劑或產品比較 | 必須載入 |
| 詢問原料來源、植物學名、化學源頭、萃取／濃縮、純度或製造來源 | 必須載入 |
| 提供標示照片、截圖、網址或成分表要求辨識 | 必須載入；先轉錄再分析 |
| 明確提到狗 | 載入本 Skill，額外查犬隻證據與安全性 |
| 明確提到嘿姆 | 先本 Skill，再依需要串接 `hemo`；不得自動把一般結論當個案醫囑 |
| 沒有提到嘿姆 | 一般查詢；不自動載入嘿姆病史、飲食、心腎限制或個案檔 |
| 純粹要求建立／修改 Skill | 交由 Skill Creator／make-skill，不由本 Skill 取代 |

## 3. 不負責與禁止

- 不把品牌宣稱、人體每日參考值、成人用量或產品食用方式直接當成動物或其他物種的劑量與療效。
- 不把「天然」「草本」「食品級」「無西藥」或「安全檢驗」直接等同於安全或有效。
- 不猜測模糊照片、未揭露含量、標準化比例、污染物、原料產地或製造來源；缺資料標 `UNKNOWN`。
- 不把俗名相似的植物視為同一物種；植物盡量核對學名、科別、部位與加工方式。
- 不將總產品重量、每份含量、原料投料量、萃取倍率與活性成分量混為一談。
- 不下診斷、開藥、停藥、調藥或替代醫療專業；疑似急性暴露或不良反應應轉交適當專業與急診資源。

## 4. 固定逐項流程

### A. 輸入與產品身分

記錄品牌、品名、規格、劑型、批次、每份大小、日期與網址；未知寫 `UNKNOWN`。從照片或網址逐字轉錄，不能確認的文字標 `TRANSCRIBED_FROM_IMAGE`／`UNKNOWN`。分開主成分、營養素、草本、礦物、藥理活性成分與賦形劑。

### B. 來源鏈

對每項成分建立：原標示名稱 → 同義名／化學名 → 植物、動物、礦物、發酵或合成源頭 → 使用部位與加工方式 → 萃取／濃縮／鹽化／標準化 → 純度與檢驗 → 原料產地與成品製造地。原料產地與製造地分開記錄；「某地製造」不等於原料都來自該地。

植物要核對學名、科別、部位與易混淆物種；化學成分要核對鹽類、酯類、來源型態與實際含量。產品未揭露的欄位不得補推。

### C. 證據分層

依序區分：官方標籤／原廠規格、政府／藥典、適用物種的獸醫或醫學資料、同行審查研究、其他物種資料、品牌宣稱、機制推論。每項成分分開寫「已知事實」「可能用途」「證據限制」「合理推論」「不能判定」。

### D. 安全性與適用性

檢查已知不良反應、暴露量、重複攝取、交互作用、特殊族群、產品類別與品質控制。若明確提到狗或其他動物，增加物種、體重、年齡、疾病、用藥與動物資料；若明確提到嘿姆，完成通用分析後才交給 `hemo` 做個案與營養換算。不得自行給「每天幾錠」或把人用量換成動物量。

## 5. 標準輸出

每項至少輸出：

`原標示名稱｜含量與單位｜成分身分｜來源／源頭｜可能用途｜適用對象證據｜合理推論｜已知風險｜交互作用｜資料缺口｜目前判定`

狀態使用：`SUPPORTED`、`LIMITED_EVIDENCE`、`THEORETICAL`、`UNKNOWN`、`NOT_READ`、`CONFLICT`、`BLOCKED`。不得把 `UNKNOWN`、`NOT_READ` 或 `NOT_RUN` 升格成安全、有效或通過。

若輸入是動物成分查詢，輸出中明確分開「一般成分功能」與「該物種／個案適用性」。若輸入是嘿姆，另標 `OWNER_REPORTED`、`VETERINARIAN_CONFIRMED` 或其他個案狀態，且不將通用分析直接寫入個案紀錄。

## 6. 相依與權限

| 相依 | 用途 |
|---|---|
| `deep-research` | 需要外部、最新或多來源證據時 |
| `image-processing`／`read-special-images` | 照片或截圖文字不清時 |
| `hemo` | 只有明確涉及嘿姆、犬隻營養換算、心腎病或其個案資料時 |
| IRIS、ACVIM、WSAVA、AAHA、MSD、VCA或同行審查來源 | 動物與獸醫問題的適用證據 |

允許讀取、整理、查核、比較與提出專業核對問題；禁止未授權外部寫入、個案寫入、給藥或正式採用。不得保存金鑰、密碼、Token、個資或非必要識別資訊。

## 7. 失敗處理

| 情況 | 出口 |
|---|---|
| 標示模糊 | 保留原圖位置，標 `UNKNOWN`，不猜測 |
| 產品頁與包裝衝突 | 並列來源，標 `CONFLICT`，停止相依結論 |
| 俗名無法對應學名 | 標 `UNKNOWN`，不宣稱源頭 |
| 只有人體／其他物種資料 | 明確標示適用物種，不轉寫成目標對象療效 |
| 未揭露活性含量 | 標 `UNKNOWN`，不以總萃取重量代替 |
| 外部來源讀不到 | 標 `NOT_READ`／`BLOCKED`，只停依賴該來源的判斷 |
| 疑似誤食或急性反應 | 不自行處理劑量，轉交獸醫、醫師、毒物或急診資源 |
